JSON 工具箱 — 隐私政策

适用版本：1.1.5（含 JSON 响应接收与本地评价邀请）　最后更新：2026 年 10 月 29 日

JSON 工具箱在您的浏览器中处理数据。开发者不接收、不收集、不出售您的 JSON 内容、本地文件、剪贴板内容或存档。

1. 本地数据处理

您主动输入、粘贴、拖放、通过文件选择器导入，或授权插件从 JSON 响应文档接收的文本和文件，仅在浏览器本地用于编辑、格式化、压缩、校验、排序、脱敏、格式转换和 Diff 对比。扩展不将这些内容上传至开发者服务器或第三方服务，也不需要账号或在线后端。

2. 本地保存与恢复

  • 浏览器 localStorage 保存语言、工具设置、脱敏规则和引导偏好。
  • 浏览器 IndexedDB 保存本地存档、Diff 草稿和标签页管理记录。使用存档或 Diff 时，相应内容可能被保存以便恢复。
  • chrome.storage.local 保存响应接收开关，以及评价邀请使用的首次记录日期、有效使用次数、最多三个使用日、最近计数时间、有限数量的随机去重标识、展示次数、冷却时间和您的选择。评价邀请不保存 JSON 内容、字段、文件名或来源地址；多个扩展标签页通过短期协调记录避免重复展示。chrome.storage.session 保存响应接收的短期协调状态。独立 IndexedDB 临时保存待导入的响应正文及来源地址；来源查询参数可能包含敏感内容，仅用于返回来源页面，界面显示时不含查询参数。编辑器确认导入后删除正文，短期来源记录和过期记录在后续使用或后台同步时清理；票据有效期为 30 分钟，上传中票据为 5 分钟。
  • sessionStorage 保存临时标签页标识。扩展通过浏览器内部的 BroadcastChannel 协调同一扩展的标签页，不向互联网发送该信息。

这些数据保存在您当前浏览器的扩展存储空间中，不会由本扩展同步到开发者或第三方服务器。网站版本与扩展版本使用独立的存储空间。

3. 文件、剪贴板与下载

文件读取由您主动选择或拖放触发。复制、粘贴、双击预览字符串等交互可能使用剪贴板；结果导出由您主动下载到本地。扩展不会后台监控剪贴板，也不会扫描您电脑上的其他文件。

4. 网络与浏览活动

处理脚本、编辑器、转换模块和 Worker 均随扩展打包，本扩展的内容安全策略将网络连接限制在扩展自身资源。响应接收默认开启。安装或升级时由浏览器按权限规则统一确认 HTTP/HTTPS 网站访问；插件仅在浏览器允许的范围通过轻量内容脚本识别顶层 JSON 响应文档，将已获得的原文导入本地编辑器。用户主动点击扩展图标时，也可临时读取当前 JSON 文档。普通网页不自动导入，不监控网页所有网络请求，不读取浏览历史或浏览器 Cookie；不会为导入再次请求原接口。用户可在通用设置中关闭自动接收，关闭不会撤销安装时的权限。浏览器内部页面等受限地址不在处理范围；网站访问及隐身等限制仍由浏览器控制。Cookie 格式转换仅处理您主动输入的文本，不访问浏览器 Cookie。

本扩展不包含广告、在线分析统计、用户追踪或远程执行代码。本地使用计数仅用于选择合适的评价邀请时机，不会上传。只有您主动点击“去评价”时，才会打开 Chrome 应用商店；该点击会停止后续邀请，但扩展不能得知您是否实际提交了评价。

5. 数据删除与控制

您可以在工具内清空当前编辑内容、删除不再需要的存档，或使用浏览器提供的存储管理功能清除扩展数据。清空当前编辑区不等于删除所有存档或本地设置；卸载扩展会移除其扩展存储数据。重要内容请事先下载或导出备份。

6. 数据共享与用途

开发者无法读取您的本地处理内容，也不会将其出售、共享或用于广告、画像、信用评估等其他用途。本扩展对用户数据的使用限于本地 JSON 编辑、处理、响应导入，以及依据本地计数展示评价邀请。您可通过“不再提示”停止邀请；拒绝或关闭邀请不影响工具功能。

7. 联系与政策更新

如有隐私问题，请联系：bing.devsec@gmail.com。若后续版本的数据处理方式发生变化，我们会更新本政策、商店披露及相应版本说明。
