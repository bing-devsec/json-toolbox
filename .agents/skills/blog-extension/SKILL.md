# JSON 浏览器扩展开发

源码路径相对于本扩展仓库。先确认任务是扩展专用修复，还是用户要求与网页工具同步的能力；两端的应用外壳和数据流不同。

主题外观开发、修复或验收时，按需读取 [临时主题核查](../blog-extension-theme-check/SKILL.md)，对照这轮纸感主题暴露的共性问题；不要求普通引擎任务加载该清单。

## 修改边界

- 入口是 src/App.vue、src/components/JsonToolWorkbench.vue；JSON 引擎、composables 与 Workers 位于 src/components 下。
- 对照源码对照说明.md 与当前文件差异。它是映射线索，不是自动同步脚本；按语义比较目标模块，不从网页整文件覆盖扩展。
- 扩展是独立本地工具。保留 scripts/check-local-only.mjs 检查的无博客 API、无远程功能、无 host permissions/content scripts 以及本地 CSP；共享代码不应带入 Nuxt runtime、分享、远程获取或风控接口。
- 解析、格式化、数字字面量和转义等语义与已约定的网页能力保持兼容。行为变更添加独立预期回归；不要用 JSON.parse/stringify 当作现有引擎的等价替换。
- 保持 Worker 取消/过期响应隔离、Monaco 与事件资源清理、本地设置/存档兼容。大型文本避免无谓复制或每次键入全文扫描。
- package.json、public/manifest.json 及打包元信息只在版本任务需要时共同修改，不因代码修复自行升版或提交商店。

## 按字段排序的路径语义

这是轻量 JSONPath 风格语法，不是完整标准 JSONPath。**排序范围**选择待排序的数组或 Map（JSON 对象）；**排序字段**相对于数组元素或 Map 的 value，例如 `id` 或 `user.profile.age`，不重复填写范围前缀或 Map 的 key。

四个 Demo 是可以嵌套组合的基本用法：

| 数据结构 | 排序范围 | 排序字段 | 含义 |
| --- | --- | --- | --- |
| 根数组 | 留空 | `id` | 按元素的 `id` 重排根数组。 |
| 根数组中的子数组 | `[*].education` | `graduationYear` | 分别排序每个人的教育经历，保留人员顺序。 |
| 根 Map | 留空 | `id` | 按各 value 的 `id` 重排 Map 条目。 |
| 根 Map 的嵌套字段 | 留空 | `value.score` | 按各 value 内的嵌套字段比较，保留既有字段回退约定。 |

- 根数据留空的用法也可下沉到显式范围：`level2.level3.level4.level5.level6.level7.level8.level9.level10` + `threshold`，选中的是该层 Map，按各 value 的 `threshold` 排序；不能因它不是数组而拒绝。
- `users` + `id` 重排用户数组；`users[*]` 遍历用户元素。两者不能互换，不能自动去掉末尾 `[*]` 再排序父数组，否则嵌套范围会产生歧义。
- 每个 `[*]` 向数组元素遍历一层。末尾选中普通字段记录（如 `{id, name}`）时，不重排记录属性或父数组；选中子数组或所有 value 都是对象的 Map 时，可以分别排序这些子容器。不要把普通记录未发生排序误判为 bug，也不要一律判定末尾 `[*]` 无效。
- `users[*].rules` 可同时选中不同用户的数组或 Map，分别按相同字段排序；多层 `[*]` 只是继续遍历，不改变未被选中的父容器或兄弟数据。显式范围选中原始值 Map 时，字段留空沿用按 value 排序。
- 范围留空沿用根数组、根 Map 等既有分支，不表示隐式追加 `[*]`。核对 `useJsonSort` 和 `sortJsonByField`，保留 Map 字段回退、缺失值与高精度数字的已有比较约定。
- 字段值混合类型按固定次序比较：空值/缺失值、布尔、数值、字符串、数组、对象；降序反转，比较值相同保持原顺序。高精度数字标记按真实数值比较，普通数字字符串仍是字符串；不要使用会形成比较循环的跨类型临时字符串转换。
- Map 的整数索引键（如 "1"、"2"）受当前 JavaScript 对象枚举顺序限制，不能把重新插入属性当成可保留任意文本顺序；这不是本轮已解决的能力，不要宣称所有 Map 键形式都已覆盖。
- 智能提示与执行使用同一目标语义，保留完整路径和遍历层级；通配符候选可用于继续输入子路径。测试区分父数组、子数组、嵌套 Map 和普通记录，并覆盖多层遍历的组合。
